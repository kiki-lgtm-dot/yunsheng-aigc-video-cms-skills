# 云生工时与算力台账

把生产投入转换为可审计的成本口径。默认使用简体中文。

## 何时使用

- 核算单项目、单视频、单阶段或季度成本。
- 对比传统流程与云生流程的工时、人数、协作时间和算力。
- 为 ROI 复盘、预算或产品判断准备底表。

不要用它估算市场报价、认定财务收入，或在没有明细时补出“差不多”的实际成本。

## 输入

优先读取用户提供的台账、账单、工时记录和正式核价。至少明确：

- 统计范围：ProjectID、业务线、开始/结束时间、交付视频数与版本数。
- 人工：角色、活动工时、协作对齐工时、等待时长、人数或 FTE、人工成本口径。
- 算力：ModelRunID、模型、调用量、成功/失败次数、API/GPU 用量和账单金额。
- 其他：工具订阅分摊、外部服务、产品开发摊销及币种、含税口径。
- 对比基线：同范围历史台账；没有则明确为缺失。

每条数据同时标记：

- source_grade：A 系统/账单/正式记录；B 带日期可复核截图或人工台账；C 用户陈述；D 外部市场基准；N 无证据。
- claim_method：direct、derived、estimated、benchmark 或 unknown。

缺失不等于 0。事实、推算、估算和外部基准必须分栏；所有数字附 period、scope、numerator、denominator、formula 与 source_id。对外可用状态默认为 false，需用户人工确认。

## 强约束

- 活动工时、协作对齐时间和自然等待时间分列；不得把交付自然日等同生产工时。
- 人数、参与人次和 FTE 分列；不得用人数下降直接推导成本下降。
- 内部实际成本、历史采购价、供应商报价和外部市场基准分列。
- API/GPU 账单按实际币种、汇率日期、税费和项目分摊规则记录。
- 失败尝试与返工算入实际投入；缓存、赠送额度或包年资源需说明分摊方法。
- 缺少数据时输出补证清单。只有用户明确要求估算时才给区间，并逐项写出假设。

## 工作流

1. 锁定统计粒度与时间边界，排除范围不一致的记录。
2. 建立逐条 CostEntry；去重但保留原记录 ID。
3. 将人工、算力、工具和外部服务归入阶段：需求、Brief、方案、脚本、分镜、生成、后期、审核、交付、归档。
4. 计算总量和单位成本，并把无法分摊的费用单列。
5. 与同口径基线比较；不同口径只做差异说明，不强行计算提升比例。
6. 输出证据覆盖率与待补证项，不自动转成履历结论。

## 计算口径

- 新流程交付 OPEX = 人工成本 + 算力/API + 约定工具分摊 + 外部服务。
- 转型投入 = 产品开发、接入、迁移和一次性建设成本。
- 全口径成本 = 新流程交付 OPEX + 转型投入。
- 单视频交付 OPEX = 新流程交付 OPEX ÷ 同范围已验收视频数。
- 全口径单视频成本 = 全口径成本 ÷ 同范围已验收视频数。
- 活动工时减少率 =（基线活动工时 - 当前活动工时）÷ 基线活动工时。
- 协作时间减少率单独计算，不与活动工时重复相加。
- 生成成功率 = 达到预设技术门槛的生成次数 ÷ 有效生成次数；门槛必须随记录给出。

分母为零、缺失或口径不一致时不输出百分比。

## 固定输出

1. 统计范围与口径。
2. 成本汇总：人工、算力、工具、外部服务、摊销、总计。
3. 阶段台账：CostEntryID、阶段、角色/模型、数量、单价、金额、source_id、source_grade、claim_method。
4. 工时视图：活动工时、协作工时、等待时长、人数、FTE。
5. 单位经济性：单项目、单视频、单成片分钟；仅输出可计算项。
6. 基线对比与差异解释。
7. 证据覆盖率、异常记录与补证清单。

## 停止条件

若统计周期、交付数量或成本来源无法确定，先输出待确认问题，不给总成本或提效结论。任何写入财务系统、修改账单或对外发布都需要用户另行授权。
