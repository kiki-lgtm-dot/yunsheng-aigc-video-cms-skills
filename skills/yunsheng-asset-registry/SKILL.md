# 云生资产入库与血缘

将交付结果沉淀成可搜索、可复用、可追责的 CMS 资产。默认使用简体中文。

## 何时使用

- 成片验收后归档项目资产。
- 脚本、分镜、角色、场景、Prompt 或模型参数具备复用价值。
- 需要追踪资产从哪个 Brief、版本、模型运行和人工修改产生。

不用于把未验收候选、权利不明素材或需求方专属资产默认开放复用。

## 输入

- AssetID、ProjectID、DeliverableVersion、上游 Brief/脚本/分镜版本。
- 资产文件或稳定引用、类型、格式、尺寸、时长、校验值。
- ModelRunID、模型版本、Prompt/负向词、参数、参考素材和人工修改记录。
- 品牌、品类、场景、风格、人物/产品标签。
- 版权、肖像、字体、音乐、IP、供应商及生成平台的使用许可。
- 需求方验收记录、适用范围、失效时间和保密级别。

## 强约束

- 缺失不等于 0；事实、推算、估算和外部基准分栏。所有数字带周期、范围、分母/公式和 source_id。source_grade 中 A=系统/账单/正式记录，B=带日期可复核截图或人工台账，C=用户陈述，D=外部基准，N=无证据；claim_method 使用 direct/derived/estimated/benchmark/unknown。对外使用默认需人工确认。
- 文件存在不等于资产可复用；先判定权利、验收与保密范围。
- Prompt、参数和模型版本属于生成血缘，不等于生成结果的权利证明。
- 未知字段写 unknown/待补证，不用“默认可商用”等表述。
- 已确认资产不可原位覆盖；修改产生新版本并保留父子关系。
- 脱敏副本与内部原件使用不同 AssetID，并记录转换规则。

## 工作流

1. 判断资产是否达到入库门槛：可定位、可识别版本、有来源、有权利状态。
2. 计算或记录唯一标识和文件校验值，识别重复与派生关系。
3. 建立 AssetCard，并关联项目、验收、生成运行和父资产。
4. 赋予标签、搜索字段、复用限制与到期检查日期。
5. 生成复用建议：可直接复用、需品牌适配、需重新授权、禁止复用。
6. 若资产被后续项目引用，追加 UsageRecord，不改写原始来源。

## 固定输出

1. 入库结论与阻断原因。
2. AssetCard：AssetID、类型、名称、版本、文件引用、校验值、状态。
3. Lineage：ProjectID、BriefID-Version、父资产、ModelRunID、人工修改。
4. Rights：权利人、许可来源、适用范围、地域/渠道/期限、保密级别。
5. Retrieval：品牌、品类、场景、风格、人物、画幅、时长等标签。
6. ReusePolicy：允许方式、必改项、禁止项、失效时间。
7. UsageRecord 模板与缺失证据。

## 停止条件

权利、验收或文件版本任一关键项不明时，只能建立 restricted/draft 资产卡，不标记 reusable。上传、删除、迁移或开放共享需要用户另行授权。
