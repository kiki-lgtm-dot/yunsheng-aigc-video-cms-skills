# 云生 ROI 与提效复盘

以同范围、同质量、同交付口径回答云生是否真正创造价值。默认使用简体中文。

## 何时使用

- 项目完成后复盘成本、周期、工时和质量。
- 按季度汇总指定业务线的交付单数、视频数与对应核价。
- 为管理汇报、产品判断或简历准备脱敏证据。

不用于财务审计、确认公司收入，或拿外部均价替代内部真实台账。

## 输入

- 统计周期、业务范围、项目清单、交付单数、已验收视频数和成片分钟数。
- 当前流程：活动工时、协作工时、人数/FTE、算力/API、工具费、外部服务、产品开发摊销。
- 对比基线：历史内部成本、历史采购价或同范围供应商可比报价。
- 周期、修改轮次、首轮通过、验收问题、资产复用等质量与效率指标。
- 每项数据的来源、公式、负责人、更新时间和数据状态。

证据使用两条独立轴：

- source_grade：A 系统/账单/正式验收；B 带日期可复核截图或人工台账；C 用户陈述；D 外部市场基准；N 无证据。
- claim_method：direct、derived、estimated、benchmark 或 unknown。

缺失不等于 0。事实、推算、估算和外部基准分栏；每条结论包含 claim_id、period、scope、numerator、denominator、formula、source_id、source_grade、claim_method、confidence、external_use_allowed=false。

## 强约束

- 交付金额、内部核价、可比采购成本、节省金额、营收分列；无财务确认不得写营收。
- 对比对象必须在视频规格、复杂度、质量门槛、修改轮次和交付范围上可比。
- 统计结论必须带时间范围、对象范围、公式和来源。
- 只把与产品机制存在证据链的变化归因于云生；同期人员、预算或业务变化单列。
- 保守、基准、扩展情景不得混写成一个确定值。
- 任何既有条数、金额或传播量都不是默认事实，只有本次证据支持才可使用。

## 计算口径

- baseline_delivery_cost = 同范围历史交付成本或完成可比性校正的报价。
- new_delivery_opex = 人工 + 算力/API + 约定工具分摊 + 外部服务。
- transformation_investment = 产品开发、接入、迁移和一次性建设投入。
- all_in_cost = new_delivery_opex + transformation_investment。
- gross_savings = baseline_delivery_cost - new_delivery_opex。
- net_benefit = baseline_delivery_cost - all_in_cost。
- savings_rate = net_benefit ÷ baseline_delivery_cost。
- transformation_ROI = net_benefit ÷ transformation_investment；仅在转型投入完整、分母大于 0 且统计周期匹配时使用“ROI”名称。
- 周期、活动工时、协作工时、人数和 FTE 分别比较。

分母缺失、为零或口径不一致时，不输出比例。

## 工作流

1. 锁定项目清单和周期，生成脱敏 ProjectAlias。
2. 校验交付与验收范围，剔除未完成或不可比项目。
3. 汇总实际成本和基线成本，逐项标注证据等级。
4. 计算单位成本、工时、周期和质量指标，检查双重计算。
5. 建立“产品机制→行为变化→业务结果→证据”归因链。
6. 输出保守/基准情景与敏感项。
7. 生成内部完整版和脱敏履历候选；履历候选仅使用 A/B 级或明确标注的 C 级数据。

## 固定输出

1. 统计范围、项目清单摘要与口径。
2. 交付规模：单数、视频数、版本数、成片分钟、验收状态。
3. 投入：人工、协作、算力、工具、外部服务、摊销。
4. 基线来源与可比性调整。
5. 节省金额、ROI、成本降低、工时/周期/人数变化。
6. 质量护栏与归因说明。
7. Claim 表：claim_id、周期、范围、分子/分母、公式、来源、证据等级、计算方式、置信度。
8. 证据矩阵、覆盖率、待补证项。
9. 脱敏履历候选：结论、周期、对象、数字、证据位置；未达证据门槛的内容不得输出为事实。

## 停止条件

缺少项目清单、验收数量、实际成本或可比基线时，只生成复盘框架和补证清单。对外发布、写入简历或向管理层发送均需用户确认最终数字与措辞。
